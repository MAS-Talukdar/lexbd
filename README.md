# Bangladesh Case Law Directory

A searchable digital repository of published
judgments of Bangladesh Courts.

## Technology Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Storage
- Cloudinary

### Authentication
- Express Session
- bcrypt

## Project Structure

- frontend/
- backend/

## Installation

Clone the repository.

Install backend dependencies:

cd backend
npm install

Create a .env file using .env.example.

Start development server:

npm run dev
